# Seguridad

Proyecto personal sin autenticación integrada ni SLA de seguridad. No exponer con datos reales sin control de acceso.

Para un fallo sensible, usa **Security → Report a vulnerability** si está habilitado. Si no lo está, contacta al propietario mediante un canal privado acordado. No publiques secretos, corpus reales ni detalles explotables en issues públicos.

Incluye commit, reproducción sin datos reales e impacto. Revoca secretos expuestos: borrarlos de Git no elimina su historial.
