# Contribuir

Abre un issue antes de cambios amplios. En un pull request describe el problema, cambio y comprobaciones.

- No incluyas corpus reales, secretos, bases ni capturas privadas.
- Revisa pedagógicamente niveles, fórmulas y respuestas.
- Ejecuta las comprobaciones del README y revisa la interfaz si la modificas.
- Comunica problemas sensibles según SECURITY.md.
- Comprueba derechos y licencias de materiales externos; el código propio todavía no declara licencia open source.
